# CloudMedix Company Overview

## Business Description
CloudMedix is a 50-person healthcare SaaS startup providing a cloud-based patient portal. Patients can view medical records, message providers, and schedule appointments.

## Tech Stack
- Web application hosted on cloud infrastructure (Linux servers)
- PostgreSQL database
- REST API backend
- React frontend

## Data Handled
- Protected Health Information (PHI): patient names, medical records, insurance details
- Employee PII
- Authentication credentials and API keys

## Regulatory Context
CloudMedix is subject to HIPAA requirements as a Business Associate handling PHI.

## Current Security Posture
The company is early stage. It has basic authentication on its application but no formal security program, no documented policies, and no dedicated security team. The CTO handles security part-time.
